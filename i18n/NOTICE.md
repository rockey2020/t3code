# Localization attribution

Native web and mobile localization follows upstream pingdotgg/t3code GT runtime and catalogs. Remaining community coverage and desktop menu translations were adapted from [deepfry666/t3code-cn](https://github.com/deepfry666/t3code-cn), commit [999518fdc18950d36d009664f0bc2f8a7f6687ca](https://github.com/deepfry666/t3code-cn/commit/999518fdc18950d36d009664f0bc2f8a7f6687ca), based on upstream commit `dab06c0be19b9d6e109f5538c6ddc92f7f15fb6b`.

The community adapter shares upstream language settings; it is retained only for views not yet migrated upstream. Only localization and its supporting tests and maintenance tools are carried here. The donor's release workflows, update servers, signing setup and distribution identity are not imported. This is an unofficial community localization, not an official T3 Tools release.
